# CareerPilot 

## 🌐 Live Project
https://career-pilot-mocha-phi.vercel.app/

## About the Project

CareerPilot is a full-stack career guidance platform developed for students. It helps students prepare for their career in one place by providing resume analysis, DSA practice, mock interviews, job recommendations, and progress tracking.

Users can create an account and manage their profile, including education, skills, career goal, GitHub, and LinkedIn details. The Resume Analyzer allows users to upload a PDF resume, detect skills and sections, get a resume score, and receive improvement suggestions.

The DSA Tracker helps users add and solve coding problems based on topic and difficulty. The Mock Interview section provides HR and technical questions with scores and feedback. Users can also set their job preferences and view suitable job recommendations.

The project uses React for the frontend, Node.js and Express.js for the backend, and MongoDB Atlas for storing user data. JWT and bcrypt are used for authentication and security.

## 🛠️ Tech Stack

**Frontend:** React, JavaScript, Vite, CSS, React Router  
**Backend:** Node.js, Express.js, REST API, JWT, bcrypt  
**Database:** MongoDB Atlas, Mongoose  
**Tools:** Git, GitHub, VS Code, Vercel
