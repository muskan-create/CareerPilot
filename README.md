# CareerPilot 🚀

## About the Project

CareerPilot is a full-stack career guidance platform developed to help students prepare for their software development careers in one place. The platform allows users to create an account, manage their profile, check their resume, practice DSA problems, prepare for mock interviews, explore job opportunities, and track their overall progress.

The frontend of CareerPilot is built using React, JavaScript, Vite, and CSS. The backend is developed using Node.js and Express.js, which provides REST APIs for user authentication and other application features. MongoDB Atlas is used to store user profiles, resume information, DSA progress, and interview data.

After registering and logging in, users can complete their profile by adding their education, skills, career goal, GitHub, and LinkedIn details. The Resume Analyzer allows users to upload a PDF resume and checks the resume content, detects technical skills and sections, calculates a resume score, matches the resume with a selected role, and provides suggestions for improvement.

The DSA Tracker helps users maintain a list of coding problems and track their solved problems based on topic and difficulty. The Mock Interview section provides HR and technical questions where users can practice their answers and receive scores and feedback. Users can also set their preferred job role, location, and job type to get suitable job recommendations.

A progress dashboard brings the important information together, such as profile completion, resume score, DSA progress, and mock interview performance. JWT authentication and bcrypt are used to provide secure login and protected user features.
